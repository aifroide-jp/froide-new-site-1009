# フロイデ TOPページ 修正版

作成日：2026年10月9日

## 開き方

`00_top.html` をブラウザーで開いてください。`index.html` からもTOPを開けます。
スクリーンショット用の静止画モードは `00_top.html?static=1` です。通常表示では控えめなフェードインと写真のパララックスが動作します。端末の「視差効果を減らす」設定でも動きを停止します。

## 修正範囲

元ZIPのTOPページを、添付Markdownのデザイン方針と末松版の文言・写真を参考に再構成しました。フレームワークに依存する出力を、通常のHTML・CSS・JavaScriptに整理しています。TOP以外の元ZIP内の21ファイルはバイト単位で一致しています。原本・参照サイト・GitHubリポジトリには変更していません。

今回の依頼に合わせてローカル成果物として保存しました。添付文書内の別途承認、新規ブランチ、コミットの手順は実施していません。

## 残すもの・外すもの

| 方針 | 対応 | 補足 |
|---|---|---|
| ネイビー背景＋ゴールド光 | 実施 | AI部分で元の2つのラジアルグラデーションを維持 |
| ネイビー・ゴールドの配色 | 実施 | #1A2B3F・#FFAF04を基準、白・グレーは参照版を継承。緊急表示の赤は指定どおり |
| フォント | 実施 | Zen Kaku Gothic New・Space Grotesk・IBM Plex Mono、参照版からローカル保存 |
| data-reveal | 実施 | 控えめなフェード、静止画モードと動きを減らす設定に対応 |
| data-screen-label | 実施 | 元の11セクション名・順序を保持。ご依頼の形と6ステップは04 AI Driven内を維持 |
| 透かし文字・大きな薄い数字 | 除去 | サービス・工程を伝える通常の番号は維持 |
| 斜めストライプ・グリッド線 | 除去 | TOPに該当装飾なし |
| SVG波形・ヒーローリング | 除去 | 面の角丸でまとまりを表現 |
| ボタンの強い光・グラデーション | 除去 | 塗り、枠線、カード内の矢印を中心に統一 |
| フッター切替・未使用パターン | 除去 | 1種類のフッターのみ |
| ローディング演出 | 除去 | 起動時にページを覆う演出なし |
| 仮画像注記・カンプ注記・事例注記 | 除去 | 指定された表示上の注記を除去 |

## 確認結果

1440・1280・768・390・375pxの各幅で、横方向のはみ出し、画像切れ、見出しの領域内のはみ出し、画面外の主要テキスト・リンクが0件。TOPのJavaScriptエラー、存在しない下層ファイルへのリンクも0件でした。

スマホメニューの開閉・Escapeキー、通常表示のフェードとパララックス、静止画モード・動きを減らす設定を確認しました。PC/スマホのスクリーンショットを目視確認しました。検証の記録は `verification.json` に保存しています。

- `screenshots/top-1440.png`：PC幅1440pxの全体
- `screenshots/top-390.png`：スマホ幅390pxの全体
- `screenshots/top-1440-first.png` / `top-390-first.png`：ファーストビュー

## 未確定の内容

- 個人情報保護方針・情報セキュリティ基本方針のページはZIPに含まれていないため、リンクを無効化しています。本番公開時にリンク先の設定が必要です。
- お知らせ5件は既存の `06_news-detail.html`、事例3件は既存の `03_case.html` へ接続しています。各項目に対応する個別詳細ページは元ZIPにありません。
- 「最大30%、納期を短縮。」などの主張と指定されたお知らせ日付・記事内容は提案用文言として反映しており、実績・公開情報との照合はしていません。
- 下層ページは既存の内容・動作をそのまま保持しています。TOPのデザイン変更は下層には反映していません。
